# SAMIL INSIGHT

삼일엘텍의 회사 검토를 위한 생산·설치·AS 품질 분석 웹 시연입니다. 실제 회사 실적, 실제 불량, 실제 고객 정보는 포함하지 않습니다. 제품명은 사용자 제공 자료에 근거한 참고 표기이며 사양·인증·수집 가능한 신호를 검증하지 않았습니다.

## 실행

Node.js 20 이상에서 프로젝트 폴더를 열고 실행합니다. 외부 패키지 설치는 필요 없습니다.

```powershell
npm.cmd start
```

브라우저에서 http://localhost:3000 을 엽니다. 종료는 터미널에서 Ctrl+C입니다. Windows에서는 `시연시작.cmd`를 실행할 수도 있습니다. 포트가 사용 중이면 `$env:PORT=3001; npm.cmd start`로 바꿉니다.

## 구성

- 경영 대시보드: 생산량, 재작업률, 설치 완료, 설치 초기 AS율, 월별·공장별·국가별 집계
- 품질 분석: 공장·제어반·인버터 조합별 비교 및 분모 공개
- 제품 이력 추적: 검색, 페이지 이동, 생산·검사·설치·AS 타임라인
- AS 인사이트: 유형별 집계, 반복 접수 제품, 미종결 및 최근 접수 이력
- 점검 우선순위: 산정 근거를 공개하는 규칙 기반 점수
- 데이터 센터: 전체 JSON 샘플 다운로드, 검증 후 원장 교체, 도입 로드맵
- 공통: 생산 기간·공장·제품 필터, 현재 조회 제품의 CSV 다운로드

## 지표 및 데이터 계약

고정 기준일 2026-10-31, 생산 기간 2025-11~2026-10. 고정 난수 시드로 제품 1,800대와 연결 AS 이력을 생성합니다. 생산 기간 필터는 **해당 기간에 생산된 제품의 코호트**를 선택하며 AS는 그 제품의 기준일까지 이력입니다. 월별 AS 발생 추세와는 다릅니다.

- 출하 전 불량률 = 재작업 발생 제품 / 생산 제품. 최종 출하 불합격률이 아닙니다.
- 설치 초기 AS율 = 설치 후 30일 이내 AS가 1회 이상 발생한 제품 / 설치 후 30일 관찰이 끝난 제품. 한 제품의 중복 AS를 중복 계산하지 않습니다. 분모 0은 `—`입니다.
- 점검 점수 = 재작업 35 + 미종결 AS 40 + 반복 AS 25. 60 이상 높음, 30 이상 관찰, 나머지 일반. 고장 확률·예측 모델·안전 판정이 아닙니다.
- 공장과 제품 비교는 구성·국가·운행 노출 차이를 보정하지 않은 기술 통계입니다. 인과관계나 우열 판정에 사용하지 않습니다.

JSON 루트는 제품 배열입니다. 제품 필드는 `id`, `productionDate`, `factory`, `model`, `inverter`, `country`, `status`, `defective`, `installDate`, `cases`입니다. `cases`는 `date`, `age`, `type`, `action`, `resolved`를 갖는 배열입니다. `age`는 설치 후 접수일까지 정수 일수입니다. 데이터 센터에서 완전한 샘플을 받을 수 있습니다. 설치 미완료 제품은 `installDate: null`, `cases: []`여야 합니다.

이번 버전의 입력은 JSON, 출력은 JSON 전체 샘플 및 필터된 제품 CSV입니다. 엑셀·CSV 가져오기와 회사별 컬럼 매핑은 실제 양식을 확보한 후 추가해야 합니다. CSV 출력은 AS 상세를 담는 백업 형식이 아닙니다.

## 검증

```powershell
npm.cmd test
```

원장 재현성·날짜 무결성·중복 제조번호·초기 AS 분모와 중복 접수·필터 교집합·점검 근거를 검증합니다.

## 운영 전환 범위

현재는 서버에 데이터를 저장하지 않고 브라우저 메모리에서 처리합니다. 새로고침 시 초기화됩니다. 인증·사용자 권한·DB·감사 이력·백업·ERP 연동·모델 학습은 구현 범위에 포함되지 않습니다. 실제 데이터는 비식별화한 뒤 검토하고, 운영 도입 전 별도로 접근 통제 및 데이터 수집 체계를 구축해야 합니다. Google Fonts 연결이 불가능하면 시스템 글꼴로 표시되며 앱 핵심 기능은 로컬에서 동작합니다.
