# SAMIL INSIGHT

삼일엘텍 승강기 업무를 연결하는 통합 관리 시연입니다. 회사 로고를 적용한 PC·모바일 화면에서 고객·건물, 승강기, AS, 점검, 부품, 기사, 계약을 관리합니다.

## GitHub Pages 공개 시연

GitHub Pages에서는 로그인 없이 가상 데이터로 체험합니다. 변경 내용은 **각 브라우저에만 저장**되며 다른 방문자와 공유되지 않습니다. 관리/조회 역할 전환은 시연 기능이며 실제 접근 제어가 아닙니다.

**동종업계 실적 비교**에는 공개 감사보고서에서 확인한 실제 실적과 원문 링크가 표시됩니다. 페이지에 표시된 자료 확인일 기준입니다.

```powershell
npm.cmd run preview:pages
```

미리보기: http://127.0.0.1:3020/finalproject/

배포는 저장소 **Settings → Pages → Source: GitHub Actions**로 설정한 뒤 변경 사항을 `main`에 push합니다. 워크플로가 테스트를 통과하면 시연 전용 `dist/pages/`를 배포합니다. 빌드만 실행하려면 `npm.cmd run build:pages`를 사용하세요.

자세한 배포 절차와 제한: [GITHUB_PAGES.md](./GITHUB_PAGES.md)

## 로컬 서버 실행

Node.js 22 이상에서 외부 패키지 설치 없이 실행합니다. 이 방식은 관리자 로그인과 권한 부여, 서버 저장을 지원합니다.

최초 실행 시:

```powershell
$env:ADMIN_USER='admin'
$env:ADMIN_PASSWORD='여기에-12자-이상-초기비밀번호'
npm.cmd start
```

접속: http://127.0.0.1:3000/

최초 생성 후에는 저장된 계정을 사용하며 환경 변수로 비밀번호를 덮어쓰지 않습니다. 기존 계정 파일이 있으면 `npm.cmd start`만 실행합니다. `PORT` 환경 변수로 포트를 바꿀 수 있습니다.

관리자는 사용자 계정 생성과 조회 권한 부여·회수를 할 수 있습니다. 일반 사용자는 허가받은 경우만 조회하며 서버에서 쓰기 권한을 검사합니다. 세션은 서버 메모리에 8시간 유지하고 서버 재시작 또는 권한 변경 시 다시 로그인해야 합니다.

계정은 `.private/users.json`, 관리 데이터는 `.private/management.json`에 저장됩니다. 비밀번호는 salt가 있는 scrypt 해시로 저장합니다. `.private/`는 Git과 Pages 배포에서 제외됩니다. 외부 운영으로 전환할 경우 HTTPS, 백업 및 별도 서버가 필요합니다. 현재 서버는 로컬 주소에 바인딩됩니다.

## 승강기 제어반 수주 검토

Node.js 22 이상과 Python 3.10 이상에서 실행합니다. 수주 업무는 로그인 서버에서 제공되며 기본 저장 위치는 `.private/orders.sqlite`입니다.

```powershell
python -m pip install -r requirements-orders.txt
npm.cmd start
```

최초 실행이라면 위 **로컬 서버 실행** 절차의 관리자 환경변수를 설정합니다. 로그인 후 왼쪽 **수주·설계 → 제어반 수주**로 이동합니다. 일반 계정에는 **권한 관리**에서 조회 권한과 수주 검토 권한을 부여할 수 있습니다. 조회 계정은 수주 및 저장된 파일을 읽고 내려받을 수 있습니다.

GitHub Pages의 같은 메뉴에서는 가상 PDF·XLSX 세트로 검토·확정과 XLSX 다운로드를 체험합니다. 검토 내용은 브라우저에 저장합니다.

1. **새 수주 등록**에서 가상 문서 양식을 다운로드하거나 사례의 **문서 불러오기**를 사용합니다. 수주명과 고객사를 입력하고 발주서와 기술 사양서를 유형별로 선택한 뒤 **문서 등록 및 추출**을 누릅니다.
2. 문서별 후보를 선택하고 출처를 열어 PDF 페이지 또는 XLSX 시트·셀과 원문을 확인합니다. 일치 항목을 한 번에 반영한 뒤, 불일치와 누락 및 확인 필요 항목을 개별 검토합니다. 직접 입력에는 검토 사유가 필요합니다.
3. **검토값 저장** 후 **검토 중 초안 XLSX 다운로드**를 사용할 수 있습니다. 모든 항목의 검토값과 원문을 확인하고 확인란을 선택한 뒤 **담당자 확정**을 누르면 **확정본 XLSX 다운로드**가 표시됩니다. 확정 시각은 한국 표준시입니다.

기본 추출 방식은 PDF 텍스트·XLSX 셀에서 가상 고객사 양식의 한글·영문 항목명을 찾는 로컬 규칙입니다. 스캔 PDF에는 Tesseract OCR이 설치된 경우 OCR을 적용합니다. 기본 언어는 `kor+eng`입니다. Tesseract가 PATH에 없다면 서버 환경변수 `ORDER_TESSERACT_CMD`에 실행 파일 경로를 지정하세요. 필요에 따라 `ORDER_OCR_LANG`으로 설치한 언어를 지정할 수 있습니다. OCR을 실행할 수 없거나 신뢰도가 낮은 페이지는 원본 검토 대상으로 표시합니다.

등록 양식의 **외부 AI 전송 허용**을 선택하면 서버에서 문서 텍스트와 셀 내용을 OpenAI에 보내 후보를 추가로 찾습니다. 서버 환경변수 `OPENAI_API_KEY`로 키를 설정하며, `ORDER_OPENAI_MODEL`로 모델을 지정할 수 있습니다. 기본 모델은 [GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)입니다. AI 키가 없거나 요청에 실패하면 로컬 후보를 사용합니다. 항목별 값 비교와 숫자·단위·날짜 정규화는 코드가 처리합니다. 서버가 문서별 실제 추출 방식을 기록합니다. 별도 Python 실행 파일을 쓰는 경우 `ORDER_PYTHON`을 설정하세요.

## 주요 기능

- 통합 대시보드와 고객·건물 관리
- 승강기 제조번호·관리번호·용량·설치·운행 상태 관리
- AS 접수·기사 배정·정기점검·안전검사 일정·결과 관리
- 부품 구매·사용·교체 이력, 재고 자동 반영 및 취소
- 직원·기사 근무 상태와 배정 건수
- 승강기별 계약 연결, 갱신, 월별 청구·부분 수금·취소·미수 관리
- MMS 현장 조회·확인표·사진·조치 기록
- 가상 관제 피드, 기록 기반 예방 정비 알림, 외부 데이터 검증·수동 반영
- 목록 검색·필터·CSV 저장, 기존 분석·AI 도우미

외부 API와 실제 장비에는 연결되어 있지 않습니다. 가상 관제값과 업무 확인표는 실제 운행 판단이나 법정 검사 판정을 제공하지 않습니다. 기존 분석·AI 도우미는 가상 제품 1,800대와 로컬 검색·규칙을 이용하며 외부 AI API를 호출하지 않습니다.

세부 사용법: [부품·계약 이력 관리](./LEDGER.md), [현장·관제·시스템 연계](./OPERATIONS.md)
