# SAMIL INSIGHT

삼일엘텍 승강기 업무를 연결하는 통합 관리 시연입니다. 회사 로고를 적용한 PC·모바일 화면에서 고객·건물, 승강기, AS, 점검, 부품, 기사, 계약을 관리합니다.

## GitHub Pages 공개 시연

GitHub Pages에서는 로그인 없이 가상 데이터로 체험합니다. 변경 내용은 **각 브라우저에만 저장**되며 다른 방문자와 공유되지 않습니다. 관리/조회 역할 전환은 시연 기능이며 실제 접근 제어가 아닙니다.

**동종업계 실적 비교**에는 공개 감사보고서에서 확인한 실제 실적과 원문 링크가 표시됩니다. 페이지에 표시된 자료 확인일 기준입니다.

```powershell
npm.cmd run preview:pages
```

미리보기: http://127.0.0.1:3020/finalproject/

배포는 저장소 **Settings → Pages → Source: GitHub Actions**로 설정한 뒤 변경 사항을 `main`에 push합니다. 워크플로가 테스트를 통과하면 시연 전용 `dist/pages/`를 배포합니다. 빌드만 실행하려면 `npm.cmd run build:pages`를 사용하세요.

자세한 배포 절차와 제한: [GITHUB_PAGES.md](./GITHUB_PAGES.md)

## 로컬 서버 실행

Node.js 22 이상에서 외부 패키지 설치 없이 실행합니다. 이 방식은 관리자 로그인과 권한 부여, 서버 저장을 지원합니다.

최초 실행 시:

```powershell
$env:ADMIN_USER='admin'
$env:ADMIN_PASSWORD='여기에-12자-이상-초기비밀번호'
npm.cmd start
```

접속: http://127.0.0.1:3000/

최초 생성 후에는 저장된 계정을 사용하며 환경 변수로 비밀번호를 덮어쓰지 않습니다. 기존 계정 파일이 있으면 `npm.cmd start`만 실행합니다. `PORT` 환경 변수로 포트를 바꿀 수 있습니다.

관리자는 사용자 계정 생성과 조회 권한 부여·회수를 할 수 있습니다. 일반 사용자는 허가받은 경우만 조회하며 서버에서 쓰기 권한을 검사합니다. 세션은 서버 메모리에 8시간 유지하고 서버 재시작 또는 권한 변경 시 다시 로그인해야 합니다.

계정은 `.private/users.json`, 관리 데이터는 `.private/management.json`에 저장됩니다. 비밀번호는 salt가 있는 scrypt 해시로 저장합니다. `.private/`는 Git과 Pages 배포에서 제외됩니다. 외부 운영으로 전환할 경우 HTTPS, 백업 및 별도 서버가 필요합니다. 현재 서버는 로컬 주소에 바인딩됩니다.

## AutoCAD 도면 검토 도우미

가상 추출 JSON으로 태그 연결, 오류 후보 검사, 부품표 CSV 생성과 검토 이력 저장을 체험할 수 있습니다. DWG 직접 읽기와 AutoCAD 연결은 아직 제공하지 않습니다. [사용법·입력 형식·검증 범위](./CAD_REVIEW.md)

## 주요 기능

- 통합 대시보드와 고객·건물 관리
- 승강기 제조번호·관리번호·용량·설치·운행 상태 관리
- AS 접수·기사 배정·정기점검·안전검사 일정·결과 관리
- 부품 구매·사용·교체 이력, 재고 자동 반영 및 취소
- 직원·기사 근무 상태와 배정 건수
- 승강기별 계약 연결, 갱신, 월별 청구·부분 수금·취소·미수 관리
- MMS 현장 조회·확인표·사진·조치 기록
- 가상 관제 피드, 기록 기반 예방 정비 알림, 외부 데이터 검증·수동 반영
- 목록 검색·필터·CSV 저장, 기존 분석·AI 도우미

외부 API와 실제 장비에는 연결되어 있지 않습니다. 가상 관제값과 업무 확인표는 실제 운행 판단이나 법정 검사 판정을 제공하지 않습니다. 기존 분석·AI 도우미는 가상 제품 1,800대와 로컬 검색·규칙을 이용하며 외부 AI API를 호출하지 않습니다.

세부 사용법: [부품·계약 이력 관리](./LEDGER.md), [현장·관제·시스템 연계](./OPERATIONS.md)
