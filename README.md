# SAMIL INSIGHT

**GitHub Pages 배포를 지원합니다.** 최초 설정과 업로드 순서는 [GITHUB_PAGES.md](./GITHUB_PAGES.md)를 참고하세요. `main`에 push하면 자동 테스트를 통과한 `public/` 정적 파일을 배포합니다. 로컬 서버는 GitHub Pages에서 필요하지 않습니다.

삼일엘텍의 회사 검토를 위한 생산·설치·AS 품질 분석 웹 시연입니다. 실제 회사 실적, 실제 불량, 실제 고객 정보는 포함하지 않습니다. 제품명은 사용자 제공 자료에 근거한 참고 표기이며 사양·인증·수집 가능한 신호를 검증하지 않았습니다.

## 실행

Node.js 20 이상에서 프로젝트 폴더를 열고 실행합니다. 외부 패키지 설치는 필요 없습니다.

```powershell
npm.cmd start
```

브라우저에서 http://localhost:3000 을 엽니다. 종료는 터미널에서 Ctrl+C입니다. Windows에서는 `시연시작.cmd`를 실행할 수도 있습니다. 포트가 사용 중이면 `$env:PORT=3001; npm.cmd start`로 바꿉니다.

## 구성

처음 접속하면 업무별 설명과 시작 버튼이 있는 **처음 화면**이 열립니다. 고장 문의·보고서 작성·제품 이력·AS 처리·반복 문제·해외 답장을 카드로 선택하세요. ‘고장 문의 예시 체험하기’는 예시 제품과 질문을 자동 선택하고 결과를 바로 보여줍니다. 공장·제품 비교와 전체 현황은 관리자용 바로가기에서 확인합니다.

메뉴는 ‘시작하기 / 현장·AS 업무 / 회사 현황·관리’로 묶었습니다. 각 업무 화면 위에는 설명과 세 단계 사용 안내를 표시합니다. ‘조회 범위 바꾸기’를 펼치면 기존 기간·공장·제품 필터를 사용할 수 있습니다. 제품 목록과 점검 목록의 ‘예시 제품 기록 열기’로 제조번호를 몰라도 상세 이력을 확인할 수 있습니다.

- 경영 대시보드: 생산량, 재작업률, 설치 완료, 설치 초기 AS율, 월별·공장별·국가별 집계
- 품질 분석: 공장·제어반·인버터 조합별 비교 및 분모 공개
- 제품 이력 추적: 검색, 페이지 이동, 생산·검사·설치·AS 타임라인
- AS 인사이트: 유형별 집계, 반복 접수 제품, 미종결 및 최근 접수 이력
- 점검 우선순위: 산정 근거를 공개하는 규칙 기반 점수
- 데이터 센터: 전체 JSON 샘플 다운로드, 검증 후 원장 교체, 도입 로드맵
- 공통: 생산 기간·공장·제품 필터, 현재 조회 제품의 CSV 다운로드

## API 없이 사용하는 AI 업무 지원 시연

왼쪽 **AI 업무 지원** 메뉴에 네 가지 업무 화면을 추가했습니다. ‘시연 제품 선택’으로 AS 이력이 있는 제품을 선택한 뒤 시작하세요. 공통 필터는 AI 화면에도 적용됩니다.

| 화면 | 실제 동작 | 시연 한계 |
| --- | --- | --- |
| AI 기술지원 | 질문 키워드와 가상 체크리스트 매칭, 선택 제품 이력 요약, 동일 접수 유형·모델·인버터 기반 유사 사례 검색 | 생성형 AI·의미 검색·실제 제조사 매뉴얼이 아님 |
| AS 보고서 | `증상:`, `확인:`, `조치:`, `미결:` 메모를 구조화하고 나머지 원문 보존, 편집 및 TXT 다운로드 | 미입력 작업·원인을 추정하지 않음. 원장 상태 변경 없음 |
| 반복 하자 탐지 | 두 생산 코호트의 설치 초기 AS율 비교, 표본·건수·증가 폭 기준 알림 | 규칙 기반 탐지이며 인과 분석·통계적 유의성·고장 예측이 아님 |
| 해외 문의 초안 | 선택 제품 정보를 넣은 한국어·영어·중국어 자료 요청 템플릿, 편집 및 TXT 다운로드 | 자유 번역·메일 발송 아님 |

문서 라이브러리 4건은 모두 자체 작성한 **가상 접수 체크리스트**입니다. 제품별 오류 코드나 사양·인증 값을 제공하지 않습니다. 관련 근거가 없으면 추가 정보를 요청합니다. AS 유사도 정렬은 유형 4점, 동일 제어반 3점, 동일 인버터 2점으로 계산하며 정답 확률을 의미하지 않습니다.

반복 하자 비교는 2026.07~09 생산분과 2026.04~06 생산분을 사용합니다. 두 집단에서 설치 후 30일 관찰이 완료된 제품만 집계합니다. 각 20대 이상, 최근 초기 AS 제품 3대 이상, 3%p 이상 증가가 모두 충족되면 검토 알림입니다. 조건을 충족하지 않으면 경보를 억지로 표시하지 않습니다. 필터를 좁혀 표본이 부족해지면 이를 표시합니다.

입력·답변·보고서는 브라우저 메모리에서만 처리됩니다. 공통 필터·선택 제품·업로드 원장 변경 시 생성 결과는 초기화됩니다. 보고서와 해외 초안은 메뉴 이동 전 편집 내용이 보존되며, 페이지 새로고침 시 전체 초기화됩니다. 작성 중 결과는 TXT로 내려받으세요. 외부 글꼴 요청이나 외부 AI API 통신은 없습니다.

`public/ai-engine.js`는 화면과 분리된 로컬 provider 인터페이스를 제공합니다. 향후 실제 API 도입 시 서버 측 인증·비밀키 관리·문서 접근 권한·비동기 요청 상태·출처 검증·답변 평가를 추가해야 합니다. API 키를 브라우저 파일에 넣지 않습니다.

## 지표 및 데이터 계약

고정 기준일 2026-10-31, 생산 기간 2025-11~2026-10. 고정 난수 시드로 제품 1,800대와 연결 AS 이력을 생성합니다. 생산 기간 필터는 **해당 기간에 생산된 제품의 코호트**를 선택하며 AS는 그 제품의 기준일까지 이력입니다. 월별 AS 발생 추세와는 다릅니다.

- 출하 전 불량률 = 재작업 발생 제품 / 생산 제품. 최종 출하 불합격률이 아닙니다.
- 설치 초기 AS율 = 설치 후 30일 이내 AS가 1회 이상 발생한 제품 / 설치 후 30일 관찰이 끝난 제품. 한 제품의 중복 AS를 중복 계산하지 않습니다. 분모 0은 `—`입니다.
- 점검 점수 = 재작업 35 + 미종결 AS 40 + 반복 AS 25. 60 이상 높음, 30 이상 관찰, 나머지 일반. 고장 확률·예측 모델·안전 판정이 아닙니다.
- 공장과 제품 비교는 구성·국가·운행 노출 차이를 보정하지 않은 기술 통계입니다. 인과관계나 우열 판정에 사용하지 않습니다.

JSON 루트는 제품 배열입니다. 제품 필드는 `id`, `productionDate`, `factory`, `model`, `inverter`, `country`, `status`, `defective`, `installDate`, `cases`입니다. `cases`는 `date`, `age`, `type`, `action`, `resolved`를 갖는 배열입니다. `age`는 설치 후 접수일까지 정수 일수입니다. 데이터 센터에서 완전한 샘플을 받을 수 있습니다. 설치 미완료 제품은 `installDate: null`, `cases: []`여야 합니다.

이번 버전의 입력은 JSON, 출력은 JSON 전체 샘플 및 필터된 제품 CSV입니다. 엑셀·CSV 가져오기와 회사별 컬럼 매핑은 실제 양식을 확보한 후 추가해야 합니다. CSV 출력은 AS 상세를 담는 백업 형식이 아닙니다.

## 운영 전환 범위

현재는 서버에 데이터를 저장하지 않고 브라우저 메모리에서 처리합니다. 새로고침 시 초기화됩니다. 인증·사용자 권한·DB·감사 이력·백업·ERP 연동·모델 학습은 구현 범위에 포함되지 않습니다. 실제 데이터는 비식별화한 뒤 검토하고, 운영 도입 전 별도로 접근 통제 및 데이터 수집 체계를 구축해야 합니다. 외부 글꼴을 요청하지 않고 시스템 글꼴로 표시하므로 인터넷 없이도 앱 핵심 기능이 로컬에서 동작합니다.
